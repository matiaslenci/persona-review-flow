# Persona Review Flow

Debo rehacer la UI/UX de estas pantallas, el proceso es que tienes una lista de personas que procesar, con informacion en un header, el flujo es: recibir una lista de personas, comenzar con la primera, consultar si esa persona aparece en la segunda pantalla que te paso y muestra una tabla con opciones de busqueda, seleccionar todas las opciones, borrar las opciones seleccionadas. Luego de cada row aparecen los botones de rechazar o aceptar(rechazarlo es opcional)
Luego si aparecen personas en la consulta debe agregarlas y se marca como informar, sino se marca como no informar y aparece como inhibido.
Crea una mejor UX y una UI mas moderna pero respetando la paleta de colores #106a75 para los acentos o primary.
Para finalizar una vez que proceso todas las personas toca el boton de pasar a firma
Crea una demo con 3 personas
